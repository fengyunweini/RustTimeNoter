# v0.2.0

本次更新集中改善计时可靠性、异常恢复与资源占用。

## 变化

- 按事件发生时间处理前台切换、标题与空闲边界；无法确认的时间显示为缺口，避免错误归给其他应用。
- 新输入反证先前的空闲判断时补写修正；查询会从已记录时段扣除缺口。
- 活跃时段定期确认落盘，正常停止等待写入完成；启动和存储失败保留原始错误。
- 损坏日志保留原件并分片续写，字典修复前先备份；历史或密钥无法验证时明确报错。
- 报表统一提示缺口，CSV/JSON 增加 `record_type`。同时包含此前已进入主分支的本地日历查询、查询范围校验、导出失败时保留原文件等修复。
- 减少重复窗口解析、字符串复制和存储缓冲分配。性能测量及适用范围见 [README](https://github.com/fengyunweini/RustTimeNoter#resource-footprint) 和 [本轮测量报告](https://github.com/fengyunweini/RustTimeNoter/blob/v0.2.0/docs/idle-input-review.md)；不同负载的结果不能直接换算成整机 CPU 或内存降幅。
- Windows CI 固定执行格式检查、严格 Clippy、Debug 与 Release 测试；发布流程校验版本、主分支提交和 CI 状态，生成安装包与 SHA256 校验文件。

## 下载与升级

下载 `RustTimeNoter-v0.2.0.zip`，完整解压后运行 `install.bat`。`tracker.exe` 供手动部署，`SHA256SUMS.txt` 可用于核对两个下载文件。

新版可读取旧 v1 数据，无需迁移。建议升级前备份完整数据目录；生成缺口或续写分片后，应继续使用新版查询，旧程序不理解这些记录约定。依赖 CSV/JSON 的脚本统计活动时需筛选 `record_type = activity`。

## 验证范围

Debug 和 Release 各 189 项测试通过，严格 Clippy 通过；包含独立事件回放、存储损坏恢复和隔离进程测试。实际系统关机、休眠恢复及 SCM 服务生命周期仍需 Windows 实机验收。强制结束进程或掉电可能丢失尚未确认落盘的尾部；事件过载等无法确定的时段会保守记录为缺口。
