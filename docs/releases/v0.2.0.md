# v0.2.0

改善应用计时准确性、异常恢复和资源占用，保留轻量、自包含的 HTML 报表。

## 修复与改进

- 修复延迟切窗、标题变化和空闲边界引起的计时错误。
- 持续使用同一应用时定期保存进度，正常退出时完成待写记录；启动和存储失败保留具体原因。
- 修复损坏日志尾部影响后续记录读取的问题，恢复时保留原文件。
- 按本地日期查询与展示，修复过大查询范围和导出失败覆盖原文件的问题。
- 减少重复窗口解析、字符串复制和存储缓冲分配。性能数据见 [README](https://github.com/fengyunweini/RustTimeNoter#resource-footprint)。

## 下载与升级

下载 `RustTimeNoter-v0.2.0.zip` 并完整解压。首次安装可直接运行 `install.bat`。

已有安装时，先执行旧程序的 `tracker stop`，等待进程退出，备份完整数据目录，再运行新版 `install.bat`。
已有配置、密钥和历史记录继续使用，无需迁移。升级后使用新版查询；备份时保留完整目录，包括恢复分片和字典。

`tracker.exe` 供手动部署，`SHA256SUMS.txt` 用于核对下载文件。CSV/JSON 的 `record_type` 区分活动与未归属时段，统计活动时筛选 `activity`。
